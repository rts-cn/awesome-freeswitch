# Contributing

English | [简体中文](CONTRIBUTING.zh-CN.md)

Thanks for helping keep this list useful.

## What we accept

- Related to FreeSWITCH, and usable today.
- A reachable official page or repository.
- A clear open-source licence, or a version you can actually try.
- No ads, no long-dead or unreachable projects.

When an entry stops working, **do not delete it** — move it to [Out-dated](README.md#out-dated), so links elsewhere keep resolving and readers can see it used to exist.

## Entry format

One file per language: `README.md` for English, `README.zh-CN.md` for Simplified Chinese. **Update both files** when you add or change an entry. Link text is the project name, never a bare URL.

```markdown
- [eslgo](https://github.com/percipia/eslgo) - Event Socket client for Go, inbound and outbound modes, typed events. `MPL-2.0` `Go`
```

- **Name**: the form the project publicly uses.
- **Description**: one or two sentences saying what it is and what problem it solves. No stacked adjectives.
- **Tags**: `licence` and `primary language` in backticks at the end of the description, in both files. Write only what you can verify — one tag, or none, is fine.
- **Tag source**: taken from the project's public repository page. Leave it empty when it cannot be identified — never guess.

## Adding a language

Before adding a language, confirm two things: readers of that language actually exist (check the repository Insights referrers), and a native-speaker maintainer will proofread it long term. Without both, a translation's mistakes stay on the page forever.

## How to submit

Open a [pull request](https://help.github.com/en/github/collaborating-with-issues-and-pull-requests/about-pull-requests) describing what you added or changed.

There is no full contribution guide yet; the [awesome-go contribution guidelines](https://github.com/avelino/awesome-go/blob/master/CONTRIBUTING.md) are a reasonable reference.
